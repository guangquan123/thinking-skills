# 筛事实四步法（处理别人发来的信息）

适用：别人递来的汇报、邮件、转述、聊天记录，需要判断里面哪些是事实。

信息到手时，事实、推测、评价和情绪是混在一起的。照单全收，等于把别人的误判也接了过来，界定问题时就会带着偏差出发。

## 四步流程

### 1. 拆：切成最小陈述

把整段话切成最小陈述，每条只讲一件事：一个主语 + 一个行为或状态。"因为、所以、但是"这类连接词只负责把话串起来，本身不提供任何事实，先放一边。

### 2. 找信号：识别七类加工痕迹（最关键）

| 类别 | 定义 | 信号词 |
|-|-|-|
| 推测 | 对没核实的事下结论 | 肯定、故意、估计、八成、这样下去迟早 |
| 评价 | 判断好坏 | 很差、不合理、不靠谱、太自私 |
| 情绪 | 表达感受而非描述事情 | 气死、无语、居然、竟然、感叹号、反问句 |
| 绝对化 | 夸大范围和频率 | 所有、没人、从来、每次、大家 |
| 标签 | 给人或事归类、站队 | 那种人、老油条、他们部门 |
| 暗示 | 不明说，但引着你往某个结论走 | "他什么时候才能改正错误"（已经先认定他有错） |
| 来源不清 | 长得像事实，却不知道是谁说的 | 听说、据说、网传、有人说 |

**最难防的是披着事实外衣的推测**："他不重视这个项目"，句式平平常常，内容却是猜别人的动机，没法查证。判断的时候别看句式，看内容。

**信号词不是让你删掉**，而是提醒：这里加过工，先别当事实用。

### 3. 核验：三个问题把关

对剩下的部分逐条问：

1. **能查证吗？**有没有可查的东西：记录、数据、物证、证人。
2. **换个人查，结论一样吗？**如果答案因人而异，那就不是事实。
3. **来源能追溯吗？**说得出具体出处，出处可不可信。

判定规则：
- 三问全过 → 事实，可直接用。
- 前两问过了、来源拿不准 → 标"待确认"，别急着采信。
- 前两问过不了 → 退回推测或评价。
- "我亲眼所见"也不能直接过关：记忆会走样，视角有盲区，重要的事再找别的渠道核对一遍。

### 4. 分开放：事实与解读两栏

核验完的信息分成两栏：

- **事实栏**：可以直接用。
- **解读栏**：装推测、评价和情绪，分开存，但**别扔**。推测是调查的线索，评价注明是谁的观点、按什么标准，情绪注明是谁对什么事的反应。它们都有用，只是不能混进事实那一栏。

## 输出格式

```
### 筛事实结果

**事实**（可核查，带来源）
- <最小陈述>（来源：XX；来源待调取时注明）

**解读**（不能直接当事实用）
- 推测（待验证）：<...>
- 评价（<谁>的观点，按<什么>标准）：<...>
- 情绪（<谁>对<什么事>的反应）：<...>

依据说明：<哪些来自原文 / 哪些是 AI 判断（待核实）>
```

## 示例

输入："听说小王开会又迟到了半小时，明显不重视这个项目，大家都很不满。"

1. 拆："听说小王开会又迟到了半小时" / "（他）明显不重视这个项目" / "大家都很不满"
2. 找信号："听说" = 来源不清；"明显不重视" = 推测（猜动机）；"又" = 绝对化暗示习惯性（需查历史）；"大家" = 绝对化 + 来源不清
3. 核验：只有"迟到约 30 分钟"可查证（签到记录）
4. 两栏输出：
   - 事实：小王于某日会议迟到约 30 分钟（来源：签到记录，需调取）
   - 解读：是否第一次迟到（查历史记录，待验证）；迟到原因是什么（问本人，待验证）；"大家不满"到底是几个人（去确认，待验证）

原始信息三十来字，真事实只有一句。大多数信息都这样。**一句核实过的事实，比十句"大概其"管用。**

## 后续动作

筛完后问用户：是否需要基于事实栏继续走六步主流程，界定这个问题？
